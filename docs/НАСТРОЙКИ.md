# Настройки

Всё меняется в окне **«Настройки»** и хранится в
`%LOCALAPPDATA%\GostLib\settings.json`. То же самое доступно из консоли:

```bat
gostlib.bat config                       показать всё
gostlib.bat config --set out_dir="D:\Altium\library\GOST"
```

Ниже — то, что реально стоит настроить, и что каждый параметр меняет на деле.
Всё остальное имеет разумные значения по умолчанию.

---

## Вкладка «Библиотека»

| Параметр | Что делает |
|---|---|
| **Имя библиотеки** | как будут называться файлы: `GOST_Lib.SchLib` / `.PcbLib` |
| **Папка библиотеки** | куда класть общую библиотеку. У проектов свои библиотеки, они лежат в папке проекта |
| **Altium (X2.EXE)** | единственная связка с Altium: по этому пути программа запускает сборку (`Shift+F9`). Обычно находится сама, заполняется вручную только при нестандартной установке |
| **Подключать библиотеку автоматически** | после сборки библиотека сама появляется в списке установленных |
| **Собирать .IntLib** | одна запись в панели `Components` вместо пары «символы + посадки». Файловые `.SchLib`/`.PcbLib` при этом отключаются, чтобы не было дублей |
| **Библиотеки KiCad** | какую установку слушать, когда их несколько. После смены обновите индекс в окне импорта |
| **Папка для git** | текстовое зеркало библиотеки, см. [КОМАНДА-И-GIT.md](КОМАНДА-И-GIT.md) |
| **Выкладывать в репозиторий 3D-модели** | STEP текстовый, git его переваривает, но библиотека на сотню корпусов — это сотни мегабайт. По умолчанию выключено |

## Вкладка «ГОСТ / шрифты»

### Шрифт и кегли

| Параметр | По умолчанию | Про что |
|---|---|---|
| **Шрифт** | `GOST type B` | если шрифта в системе нет, программа скажет об этом в журнале при запуске, а текст нарисуется чем придётся |
| **Имена выводов** | 7 пт | текст внутри корпуса |
| **Номера выводов** | 6 пт | текст снаружи, над линией вывода |
| **Позиционное обозначение** | 10 пт | `DD1`, `R5` |
| **Тип в основном поле** | 10 пт | обозначение микросхемы внутри корпуса |
| **Текст таблицы разъёма** | 7 пт | «Цепь» / «Конт.» |

### Геометрия

| Параметр | По умолчанию | Про что |
|---|---|---|
| **Длина вывода** | 300 mil | вылет линии вывода за корпус |
| **Шаг выводов** | 100 mil | сетка ЕСКД; менять стоит только осознанно |
| **Поднимать шаг под кегль** | вкл. | если имена выводов крупные, шаг увеличивается сам, чтобы текст не слипался |
| **Номер над выводом** | 25 mil | подъём номера над линией |
| **Зазор между группами** | 1 строка | пустые строки между логическими группами выводов |
| **Размер двухвыводных элементов** | 1.0 | масштаб резисторов, конденсаторов и прочей пассивки |

### Что рисовать

| Параметр | Про что |
|---|---|
| **Номера выводов** | показывать ли их вообще |
| **Номера собственным текстом** | иначе их рисует Altium и кегль задать нельзя. По умолчанию включено |
| **Знаки мощности** | римские цифры внутри резистора по ГОСТ |
| **Дополнительные поля у микросхем** | вертикальные линии основного и дополнительных полей |
| **Компактные символы** | одинаковые узкие боковые поля по сетке |
| **Чёрно-белый** | цвет всей графики и текста; по умолчанию всё чёрное, как в ЕСКД |

> Цвет **обязательно** задаётся каждому примитиву явно: иначе Altium рисует
> графику синим, а текст бордовым. Настройка на это и влияет.

### Превью и 3D

| Параметр | По умолчанию | Про что |
|---|---|---|
| **Кегль в превью** | 0.72 | поправка на то, что Altium отмеряет текст по высоте прописной буквы, а Qt и SVG — по полной высоте кегля. Если на схеме подписи крупнее, чем в превью, увеличьте |
| **Подробность 3D-моделей** | 6000 треугольников | **это настройка скорости сборки, а не картинки** |
| **Сажать 3D-модели на плоскость платы** | вкл. | Altium считает `Z = 0` плоскостью платы, а модели из EasyEDA приходят с началом координат где придётся — отсюда корпуса, утонувшие в плате. Правится только смещение по высоте, сам файл не трогается. У выводных корпусов не применяется: там ножки ниже платы |

**Про подробность 3D.** Замер на живом проекте: посадка с моделью на ~58 тысяч
треугольников вставлялась в Altium **337 секунд**, соседняя посадка из 355
площадок собралась за 8,5. Шесть тысяч треугольников на корпусе микросхемы от
шестидесяти на глаз не отличаются. Габарит при прореживании сохраняется точно.

Уже скачанные модели приводятся к новому значению кнопкой **«Пережать
3D-модели»** — пережимается из исходного OBJ, поэтому операция обратима.

## Вкладка «Разъёмы»

Разъёмы по ЕСКД рисуются таблицей «Цепь | Конт.».

| Параметр | Про что |
|---|---|

## Правила группировки выводов

Отдельная вкладка в главном окне. Одна группа на строку:

```
Питание      | L | VDD*, *VDD, VCC*, VBAT*
USB          | R | USB*, D+, D-          +пара
Порт A / 0   | A | PA[0-9]*, P0.*
Земля        | L | GND*, VSS*, EP        +низ
```

Сторона — `L`, `R` или `A` (программа сама выровняет стороны). В шаблонах
работают `*`, `?` и `[A-K]`. Порядок строк задаёт порядок блоков сверху вниз.
`+пара` держит половинки дифференциальной пары рядом, `+низ` прижимает блок к
низу стороны. Подробно и про встроенный набор — в
[РАБОТА.md](РАБОТА.md#правила-группировки).

Правила бывают **общие** и **свои у отдельного компонента** — у второго они
перекрывают общие.

## Вкладка «Работа»

| Параметр | Что делает |
|---|---|
| **Импортированное сразу добавлять в текущий проект** | иначе компонент осядет только в общем каталоге |
| **Показывать кнопку «Собрать задание» (F9)** | по умолчанию выключено: обычно хватает «Собрать и запустить»; `F9` работает и без кнопки |
| **3D из EasyEDA — родной STEP производителя** | цветная точная модель вместо перегонки сетки; снимите, если модель встала криво |

## Вкладка «Экспорт в KiCad»

| Параметр | Что делает |
|---|---|
| **Имя библиотеки** | как библиотека будет называться в проекте KiCad |
| **Раскладывать по разным папкам** | символ, посадка и 3D — в свои папки, а не в одну |
| **Предупреждать, если компонент и так из KiCad** | с именами исходных символа, посадки и 3D-модели |

## Вкладка «Сервис»

Редкие действия, раньше висевшие на панели кнопкой «Запасные пути»: запасные
пути сборки (мастер импорта KiCad, EAGLE, прямая запись), журнал и команда
скрипта Altium, резервная копия и очистка, рабочая папка, пакеты для 3D,
пережатие и посадка 3D-моделей. Кнопка сохраняет настройки, закрывает окно и
выполняет действие.

## Настройки отдельного компонента

Стиль можно переопределить у одного компонента, не трогая общий: номера
выводов, масштаб УГО, компактные поля — на вкладке «УГО». Полезно, когда у
одной микросхемы имена выводов длиннее, чем у всех остальных, и общий кегль
ради неё менять не хочется.

---

## Тема и вид

- **Вид ▾ → Светлая / Тёмная тема.**
- **Вид ▾ → Колонки таблицы** — какие колонки показывать, включая произвольные
  параметры компонентов.
- **F11** — свернуть панель просмотра.

## Где что лежит

| Путь | Что |
|---|---|
| `%LOCALAPPDATA%\GostLib\settings.json` | все настройки |
| `%LOCALAPPDATA%\GostLib\catalog.sqlite` | каталог компонентов |
| `%LOCALAPPDATA%\GostLib\backups` | резервные копии |
| `%LOCALAPPDATA%\GostLib\models` | 3D-модели |
| `%LOCALAPPDATA%\GostLib\jobs` | задания, журналы и отчёты сборки |

Перенести всё на другую машину — скопировать папку `GostLib` целиком.
