КАК ЗАТАЩИТЬ БИБЛИОТЕКУ В ALTIUM — три пути, любой на выбор
============================================================

Символы во всех трёх случаях ОДИНАКОВЫЕ — свои, по ЕСКД (ГОСТ тип Б,
резисторы прямоугольниками, микрухи с доп. полями, разъёмы таблицей).
Разница только в том, ЧЕРЕЗ ЧТО они попадают в Altium.


ПУТЬ 1 — штатный импортёр KiCad  (пробуй первым)
------------------------------------------------
Файлы уже лежат тут:
    C:\Users\vakva\AppData\Local\GostLib\export\kicad\
        GOST_Lib.kicad_sym
        GOST_Lib.pretty\*.kicad_mod

В Altium:
    File -> Import Wizard -> Next
    -> "KiCad Design Files" -> Next
    -> Add -> выбрать GOST_Lib.kicad_sym
       и все *.kicad_mod из папки GOST_Lib.pretty
    -> Next до конца

Altium сам создаст .SchLib и .PcbLib и положит их в новый проект *.PrjPcb.

Если пункта "KiCad Design Files" в мастере НЕТ — надо поставить расширение:
    Settings (шестерёнка справа сверху) -> Extensions and Updates
    -> вкладка Purchased/Software Extensions -> "KiCad Importer" -> Install
    -> перезапуск Altium.


ПУТЬ 2 — импортёр EAGLE
-----------------------
Файл:
    C:\Users\vakva\AppData\Local\GostLib\export\eagle\GOST_Lib.lbr

В Altium:
    File -> Import Wizard -> Next
    -> "EAGLE Projects and Designs" -> Next
    -> Add -> выбрать GOST_Lib.lbr
    -> Next до конца

Altium сделает .SchLib, .PcbLib И соберёт .IntLib.
Этот импортёр в Altium есть всегда, ставить ничего не надо.

Файл проверен валидатором по DTD EAGLE 6.6 / 7.2 / 9.x — ошибок нет,
версия в заголовке 9.4.0 (Altium официально принимает 6.4 ... 9.4).


ПУТЬ 3 — прямая запись (как было)
---------------------------------
    C:\Users\vakva\AppData\Local\GostLib\library\GOST_Lib.SchLib / .PcbLib
    В Altium: DXP -> Run Script... -> GostLibBuilder -> RunGostLib

Это самый быстрый путь, но если Altium ругается ("File corrupted",
"I/O error 32") — не воюй с ним, бери путь 1 или 2: там .SchLib/.PcbLib
делает сам Altium, и придраться ему не к чему.


Про "I/O error 32"
------------------
Это не про формат файла. Delphi (на нём написан Altium) так показывает
системную ошибку Windows 32 = ERROR_SHARING_VIOLATION: "файл занят другим
процессом". Типичные причины: висит второй процесс Altium (X2.EXE) в
диспетчере задач, либо антивирус держит только что записанный файл,
либо файл лежит в синхронизируемой папке (OneDrive/Яндекс.Диск).
На путях 1 и 2 этой проблемы нет в принципе — там файл пишет сам Altium.


В самой утилите
---------------
На панели три кнопки конвертации:
    "Через KiCad-импортёр"          (Ctrl+B)
    "Через EAGLE (.lbr)"
    "Прямая запись .SchLib/.PcbLib"
и то же самое по правой кнопке на компоненте -> "Конвертировать в Altium".

Из командной строки:
    gostlib.bat convert kicad
    gostlib.bat convert eagle
    gostlib.bat convert binary
