# GostLib — сборка и запуск

## Собрать exe

На машине с **Windows** и Python 3.10+:

1. Положить проект в любую папку (путь без кириллицы — PyInstaller
   спотыкается о неё реже, но всё же спотыкается).
2. Установить зависимости: `pip install PySide6 olefile`
   (и `pip install trimesh cascadio`, если нужен просмотр 3D-моделей).
3. Запустить `build_exe.bat` двойным щелчком либо из консоли:

```
build_exe.bat                 обычная сборка
build_exe.bat --console       с консолью: видно ошибки и print
build_exe.bat --clean         снести build/ и dist/ перед сборкой
build_exe.bat --name MyApp    другое имя exe
```

Результат — `dist\GostLib.exe`, один файл, 60–120 МБ (с trimesh/cascadio
ближе к верхней границе). Первая сборка идёт 2–5 минут.

Иконку `gostlib\gui\gostlib.ico` сборка создаёт сама; пересобрать вручную:
`python gostlib\gui\make_icon.py`.

Собрать exe под Windows из Linux/macOS нельзя: PyInstaller упаковывает тот
интерпретатор, под которым запущен, а не кросс-компилирует.

## Если сборка ругается

* **`pip не найден` / PyInstaller ставится не туда** — виноват «чужой»
  Python. `build_exe.bat` сам берёт `.venv\Scripts\python.exe`, если venv
  есть; проверьте строку «Интерпретатор:» в начале вывода.
* **`ModuleNotFoundError` при запуске готового exe** — модуль подгружается
  лениво, и анализатор его не увидел. Добавьте его в `--hidden-import` в
  `build_exe.py` либо уберите из списка `EXCLUDE_QT` там же.
* **`PermissionError` / файл занят** — закрыт ли запущенный `GostLib.exe`.
  Плюс добавьте папку проекта в исключения антивируса: свежесобранные
  onefile-exe регулярно попадают под эвристику (вплоть до молчаливого
  удаления `dist\GostLib.exe`).
* **Странные падения после правок кода** — пересоберите с `--clean`,
  PyInstaller кэширует анализ.
* **exe запускается и молча закрывается** — пересоберите с `--console` и
  посмотрите traceback.
* **Нет trimesh/cascadio** — не ошибка. Скрипт скажет об этом и соберёт
  всё остальное; не будет только просмотра 3D и конвертации в STEP.

## Чем exe отличается от запуска из исходников

* Python, PySide6 и все зависимости уже внутри — устанавливать на целевой
  машине нечего.
* Запуск на 1–3 секунды дольше: onefile каждый раз распаковывается во
  временную папку (`%TEMP%\_MEIxxxxxx`) и удаляет её при выходе.
* Код внутри exe заморожен. Правки в `gostlib\*.py` на exe не влияют,
  нужна пересборка. Кнопка перезагрузки модуля 3D в GUI в собранном виде
  бесполезна.
* Без `--console` окна консоли нет, `print` уходит в никуда. Для отладки
  собирайте с `--console`.
* Скрипт для Altium (`GostLibBuilder.pas`), шаблоны и иконка вшиты в exe и
  распаковываются в рабочую папку при запуске — отдельно их носить не надо.

Запуск из исходников остаётся рабочим вариантом и удобнее при разработке:

```
python -m gostlib.gui.app      GUI
python -m gostlib.cli --help   командная строка
```

## Куда программа кладёт рабочие файлы

Рядом с exe она ничего не пишет. Всё лежит в **`%LOCALAPPDATA%\GostLib`**
(обычно `C:\Users\<имя>\AppData\Local\GostLib`):

| Путь | Что там |
|------|---------|
| `settings.json` | настройки (стиль ЕСКД, шрифт, пути, тема) |
| `catalog.sqlite` | база компонентов |
| `library\` | готовые `.SchLib` / `.PcbLib` / `.IntLib` |
| `models\` | 3D-модели |
| `jobs\`, `current_job.txt` | задания для Altium |
| `altium\GostLibBuilder.pas` | скрипт, распакованный из exe при каждом запуске |

Папку вывода библиотек можно переназначить в настройках. Чтобы перенести
всё на другую машину, копируется вся папка `GostLib` целиком. Чтобы
сбросить программу в исходное состояние — удалить её.
