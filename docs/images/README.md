| Файл | Что снять | Почему это |

| `main-window.png` | Главное окно целиком: таблица каталога, дерево слева, панель просмотра справа с символом, кнопки сборки на верхней панели. ## Как снимать

- Тёмная тема выглядит лучше на GitHub в обоих режимах.
- Ширина 1400–1800 px, PNG. Больше не нужно: GitHub всё равно ужимает.
- Никаких путей с личными данными в кадре — при необходимости заранее
  переключитесь на проект с нейтральным именем.
- Для пары «до/после» удобно класть два снимка рядом в одну строку таблицы
  Markdown.
