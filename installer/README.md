# Установщик GostLib для Windows

Собирает `dist\GostLib-Setup-<версия>.exe` — обычный установщик Windows
поверх готового `dist\GostLib.exe`.

## Что нужно поставить

| Что | Зачем | Откуда |
|---|---|---|
| Windows 10/11, x64 | собрать можно только на Windows | — |
| Python 3.10+ с зависимостями проекта | сборка `GostLib.exe` | см. README.md в корне |
| **Inno Setup 6.3 или новее** | компилятор установщика (`ISCC.exe`) | ставится автоматически, см. ниже |

Отдельно ставить Inno Setup не нужно. Если `ISCC.exe` не найден, скрипт
спросит разрешения и поставит его сам: сначала через `winget`, если он
есть, иначе скачает установщик с jrsoftware.org и выполнит тихую
установку. Без прав администратора ставит только для текущего
пользователя (`/CURRENTUSER`) — тогда и запроса UAC не будет.

Ищет он `ISCC.exe` в `Program Files (x86)\Inno Setup 6`,
`Program Files\Inno Setup 6`, `%LOCALAPPDATA%\Programs\Inno Setup 6`, по
записи в реестре и в PATH.

## Как собрать

```
installer\build_installer.bat
```

Скрипт сам соберёт `dist\GostLib.exe`, если его ещё нет (вызовет
`build_exe.py`), при необходимости поставит Inno Setup, затем
скомпилирует установщик. Ключи:

```
build_installer.bat --rebuild     пересобрать GostLib.exe заново
build_installer.bat --clean       снести build\ и dist\ перед сборкой
build_installer.bat --console     GostLib.exe с консолью, для отладки
build_installer.bat --yes         ставить Inno Setup без вопросов
build_installer.bat --no-install  не ставить Inno Setup, только сообщить
build_installer.bat --portable    только портативный архив, без Inno Setup
```

Только exe, без установщика — `build_exe.bat` в корне проекта.

## Что получится

```
dist\GostLib.exe                    самодостаточный exe (~60-100 МБ)
dist\GostLib-Setup-1.0.0.exe        установщик
dist\GostLib-1.0.0-portable.zip     портативный архив (собирается заодно)
```

Если Inno Setup поставить так и не удалось (нет сети, отказались), скрипт
не падает, а собирает **только портативный архив**: распаковал —
запустил. Раздавать можно и им.

Версия берётся из `__version__` в `gostlib/__init__.py` — правится там, в
одном месте. Идентификатор программы (`AppId` в `gostlib.iss`) постоянный,
поэтому новая версия ставится поверх старой как обновление.

## Чем установщик отличается от голого exe

`GostLib.exe` работает и сам по себе — скопировал и запустил. Установщик
добавляет к этому:

- установку в `Program Files\GostLib` **или** только для текущего
  пользователя, без прав администратора (выбор на первом экране);
- ярлык в меню Пуск и, по галочке, на рабочем столе;
- запись в «Приложения и возможности» — программу видно в списке и можно
  удалить штатным способом;
- корректное обновление поверх предыдущей версии;
- при удалении **рабочая папка `%LOCALAPPDATA%\GostLib` не трогается** —
  каталог компонентов, настройки и резервные копии остаются. Удалить её
  предлагается отдельным вопросом в самом конце деинсталляции, ответ по
  умолчанию — «Нет».

В реестр установщик пишет только `HKCU\Software\GostLib` (путь установки и
версия); системные ветки не затрагиваются.

## Файлы

| Файл | Что делает |
|---|---|
| `gostlib.iss` | скрипт Inno Setup: секции установки, языки, ярлыки, вопрос при удалении |
| `build_installer.py` | сборка: проверки, поиск и установка Inno Setup, подстановка версии, запуск компилятора, портативный архив |
| `build_installer.bat` | обёртка для двойного клика (CP866, берёт `..\.venv`) |
